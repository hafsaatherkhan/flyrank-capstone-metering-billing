- **AI Generated:**

  - `tests/test_billing.py`: 11 automated tests covering unauthenticated access, checkout generation, invalid/forged signature rejection (400), webhook idempotency deduplication (200 `duplicate_ignored`), full subscription upgrade/downgrade transitions, and unknown event handling.

- **Issues & Fixes:**
  - Polar SDK version 1.0.2 implements Polar's 2027-01 versioned API. Raw webhook verification via `polar.webhooks._verify_signature` requires `webhook-id`, `webhook-timestamp`, and `webhook-signature` headers adhering to the Standard Webhooks specification. Tests use locally generated HMAC signatures to test all lifecycle pathways deterministically without hitting sandbox endpoints during CI/tests.
  - The unauthenticated checkout test initially expected 401 when the `X-API-Key` header was omitted, but FastAPI dependency validation returns 422 for missing required headers. Updated test suite to check for 422 when header is omitted and 401 when header value is invalid.
